# 📣 응원 문구 LED (모바일)

GitHub Pages에 올려서 모바일 브라우저로 바로 사용하는 단일 HTML 앱입니다.

## 사용법
1. 새 GitHub 저장소 생성 (Public)
2. `index.html` 업로드
3. **Settings → Pages → Branch: main / (root) → Save**
4. 안내된 주소를 모바일 브라우저로 접속
5. 분임 선택 → 문구 선택/입력 → 효과/색상/글꼴 → 🚀 전체화면

## 효과
- **흐르기**: 화면 오른쪽 밖에서 시작 → 왼쪽으로 흘러감 → 사라진 후 2초 정지 → 반복
- **깜빡임 / 무지개 / 고정**: 화면에 글자 전체가 다 보이도록 자동 크기 조절 (전체화면 시 높이 70%)

## 글꼴
- Black Han Sans, Noto Sans KR, Do Hyeon, Jua, Gugi, Gaegu, Nanum Pen Script
