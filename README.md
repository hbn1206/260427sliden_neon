# 📣 모바일 응원 문구 LED

분임 응원용 모바일 LED 전광판 웹앱입니다. **에듀테크AI(고) 분임**, **수학 분임** 응원 문구 예시 제공.

## ✨ 기능
- 분임별 예시 문구 4종 (탭하여 즉시 선택)
- 직접 입력 / 글자색 · 배경색 / 효과(흐르기·깜빡임·무지개·고정) / 속도
- 실시간 미리보기
- **전체화면 버튼** → 폰 화면 가득 찬 LED 전광판
- 전체화면에서 **아무 곳이나 탭하면 이전 화면 복귀** (옵션 그대로 유지)
- 글씨 높이가 화면에 꽉 차도록 자동 폰트 크기 조정

## 🚀 실행 방법 (가장 쉬움 - GitHub Pages)

1. GitHub에서 새 저장소 생성 (예: `cheer-led`, **Public**)
2. `index.html` 파일을 업로드 → Commit
3. 저장소 → **Settings → Pages**
4. Source: **Deploy from a branch** / Branch: **main** / **/(root)** → Save
5. 1~2분 후 안내된 주소 (`https://사용자명.github.io/cheer-led/`)를 모바일 브라우저에서 열기
6. 홈 화면에 추가하면 앱처럼 사용 가능

> 로컬에서 그냥 `index.html`을 더블클릭해서 열어도 동작합니다.

## 📱 사용
1. 분임 선택 → 예시 탭 또는 직접 입력
2. 색상/효과/속도 선택 → 미리보기 확인
3. **🚀 전체화면으로 보기** 탭
4. 휴대폰을 가로로 돌리면 글씨가 더 큽니다
5. 화면 탭 → 설정 화면으로 돌아옴 (옵션 유지됨)
