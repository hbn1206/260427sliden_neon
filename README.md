# 🎉 응원 문구 만들기

태블릿이나 모바일에서 응원 문구를 전체화면으로 보여주는 웹앱입니다.

## ✨ 주요 기능

- 📝 **문구 선택**: 에듀테크AI(고) 분임, 수학 분임 문구 (각 4가지) 또는 직접 입력
- 🔤 **글꼴 선택**: 4가지 한글 웹폰트 (Google Fonts)
- 🎨 **배경색 선택**: 6가지 배경색 + 자동 글자색 조합
- 💡 **네온싸인**: 빛나는 네온 효과
- 🎬 **슬라이드**: 오른쪽→왼쪽 이동 효과
- ⚡ **깜빡깜빡**: 깜빡이는 효과
- 📺 **전체화면**: HTML 다운로드로 실제 기기 전체화면 지원

## 🚀 배포 방법

1. GitHub 저장소에 파일 업로드
2. [Streamlit Cloud](https://streamlit.io/cloud) 접속
3. New app → 저장소 선택 → Main file: `main.py`
4. Deploy 클릭

## 📱 사용 방법

1. 앱에서 문구, 글꼴, 배경색, 효과 선택
2. 미리보기로 확인
3. HTML 파일 다운로드
4. 다운로드된 파일을 브라우저로 열기
5. 화면 터치로 전체화면 ON/OFF
