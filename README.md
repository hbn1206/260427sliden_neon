# 🎉 응원 문구 만들기

태블릿이나 모바일에서 응원 문구를 전체화면으로 보여주는 웹앱입니다.

## ✨ 주요 기능

### 📝 응원 문구
- **에듀테크AI(고) 분임** 문구 4가지
- **수학 분임** 문구 4가지
- 직접 입력 가능

### 🎨 꾸미기 옵션
- **6가지 배경색**: 검정, 빨강, 파랑, 초록, 보라, 흰색
- **4가지 글꼴**: Black Han Sans, Jua, Do Hyeon, Gugi
- **배경색에 맞는 자동 글자색 설정**

### ✨ 효과
- 💡 **네온싸인**: 빛나는 네온 효과
- 🎬 **슬라이드**: 오른쪽에서 왼쪽으로 이동
- ⚡ **깜빡깜빡**: 글자가 깜빡이는 효과

### 📺 전체화면 모드
- HTML 파일 다운로드 방식
- 실제 기기 전체화면 지원
- 화면 터치로 전체화면 ON/OFF

## 🚀 배포 방법

### Streamlit Cloud

1. GitHub에 저장소 생성
2. `main.py`와 `requirements.txt` 업로드
3. [streamlit.io/cloud](https://streamlit.io/cloud) 접속
4. "New app" → 저장소 선택 → Main file: `main.py`
5. "Deploy" 클릭

## 📱 사용 방법

1. 웹앱에서 문구, 배경색, 글꼴, 효과 선택
2. 미리보기로 확인
3. "📥 응원 화면 다운로드" 버튼 클릭
4. 다운로드된 HTML 파일 열기
5. 화면 터치하면 전체화면 전환!

## 💡 팁

- **iOS**: Safari에서 "홈 화면에 추가"하면 앱처럼 사용 가능
- **Android**: Chrome에서 전체화면 완벽 지원
