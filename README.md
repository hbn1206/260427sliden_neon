# 🎉 응원 문구 앱

모바일에서 화면보호기처럼 전체화면으로 응원 문구를 표시하는 웹앱입니다.

---

## 📁 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 옵션 선택 페이지 |
| `cheer.html` | 전체화면 응원 페이지 |

---

## 🚀 GitHub Pages로 배포하기 (자세한 방법)

### 1단계: GitHub 저장소 만들기

1. [GitHub](https://github.com) 로그인
2. 우측 상단 **+** 버튼 클릭 → **New repository**
3. 저장소 설정:
   - **Repository name**: `cheer-app` (원하는 이름)
   - **Public** 선택 (필수!)
   - **Add a README file** 체크 해제
4. **Create repository** 클릭

### 2단계: 파일 업로드

1. 생성된 저장소 페이지에서 **Add file** → **Upload files** 클릭
2. `index.html`과 `cheer.html` 파일을 드래그하여 업로드
3. 하단 **Commit changes** 클릭

### 3단계: GitHub Pages 활성화

1. 저장소 상단 **Settings** 탭 클릭
2. 왼쪽 메뉴에서 **Pages** 클릭
3. **Source** 섹션에서:
   - **Branch**: `main` 선택
   - **Folder**: `/ (root)` 선택
4. **Save** 클릭

### 4단계: 배포 완료! 🎉

1. 1~2분 기다리면 배포 완료
2. 접속 주소: `https://사용자이름.github.io/저장소이름/`
3. 예시: `https://hong123.github.io/cheer-app/`

## 📱 모바일에서 사용하기

### 방법 1: 브라우저로 접속
1. 핸드폰 브라우저(Chrome/Safari)에서 주소 입력
2. 옵션 선택 후 **전체화면으로 보기** 클릭

### 방법 2: 홈 화면에 추가 (추천!)

#### 아이폰 (Safari)
1. Safari에서 앱 주소 접속
2. 하단 **공유 버튼** (□↑) 탭
3. **홈 화면에 추가** 탭
4. **추가** 탭
5. 홈 화면에서 앱처럼 실행!

#### 안드로이드 (Chrome)
1. Chrome에서 앱 주소 접속
2. 우측 상단 **⋮** 메뉴 탭
3. **홈 화면에 추가** 탭
4. **추가** 탭
5. 홈 화면에서 앱처럼 실행!

## 📌 사용 팁

1. **문구가 길면** 자동으로 글자 크기가 조절됩니다
2. **슬라이드 효과**는 긴 문구에 적합합니다
3. **전체화면에서 터치**하면 설정 화면으로 돌아갑니다
4. **여러 효과**를 동시에 선택할 수 있습니다

## ❓ 문제 해결

### 전체화면이 안 돼요
- iOS Safari는 전체화면 API를 제한적으로 지원합니다
- **해결**: 홈 화면에 추가하면 전체화면으로 실행됩니다

### 글꼴이 안 보여요
- 인터넷 연결 확인 (Google Fonts 로드 필요)
- 페이지 새로고침

### 화면이 잘려요
- 기기를 가로로 돌려보세요
- 짧은 문구를 선택하세요
