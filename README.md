# 🎉 응원 문구 생성기

태블릿, 모바일, PC에서 사용할 수 있는 응원 문구 표시 웹앱입니다.

## ✨ 주요 기능

- ✏️ **문구 직접 입력**: 원하는 응원 문구를 직접 입력
- 📝 **샘플 문구 선택**: 에듀테크AI(고) 분임, 수학 분임 샘플 문구 제공
- 💡 **네온싸인 효과**: 화려한 네온 조명 효과
- 🎬 **슬라이드 효과**: 문구가 슬라이드되는 애니메이션
- 📺 **전체화면 모드**: 버튼 클릭으로 전체화면 전환
- 📱 **반응형 디자인**: 태블릿, 모바일에서 바로 실행 가능

## 🚀 실행 방법

### Streamlit Cloud에서 실행
1. 이 저장소를 GitHub에 업로드합니다
2. [Streamlit Cloud](https://streamlit.io/cloud)에 접속합니다
3. "New app" 버튼을 클릭합니다
4. GitHub 저장소를 연결합니다
5. Main file path에 `cheer_app.py`를 입력합니다
6. "Deploy" 버튼을 클릭합니다

### 로컬에서 실행
```bash
pip install -r requirements.txt
streamlit run cheer_app.py
```
