# 🎉 응원 문구 만들기

태블릿이나 모바일에서 응원 문구를 전체화면으로 보여주는 웹앱입니다.

## ✨ 주요 기능

- 📝 **문구 선택**: 샘플 문구 선택 또는 직접 입력
- 🎨 **배경색 선택**: 6가지 배경색 (자동 글자색 변경)
- 🔤 **글꼴 선택**: 4가지 예쁜 한글 폰트
- 💡 **네온싸인 효과**: 화려한 네온 조명 효과
- 🎬 **슬라이드 효과**: 오른쪽→왼쪽 슬라이드
- 📺 **전체화면 모드**: HTML 파일로 기기 전체화면 지원

## 🚀 배포 방법

1. GitHub에 파일 업로드
2. [Streamlit Cloud](https://streamlit.io/cloud) 접속
3. New app → 저장소 선택 → `main.py` 지정
4. Deploy 클릭

## 📱 사용 방법

1. 앱에서 문구, 배경색, 효과 선택
2. "응원 화면 다운로드" 버튼 클릭
3. 다운로드된 HTML 파일을 브라우저로 열기
4. 화면 터치로 전체화면 전환!
