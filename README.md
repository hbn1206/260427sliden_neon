# 🎉 응원 문구 웹페이지

태블릿이나 모바일에서 사용할 수 있는 응원 문구 표시 앱입니다.

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 📝 문구 선택 | 샘플 문구 선택 또는 직접 입력 |
| 🎨 배경색 | 6가지 배경색 + 자동 글자색 조합 |
| 💡 네온싸인 | 화려한 네온 깜빡임 효과 |
| 🎬 슬라이드 | 오른쪽에서 왼쪽으로 천천히 이동 |
| 📺 전체화면 | 기기 화면 전체를 꽉 채움 |
| 👆 터치 복귀 | 전체화면에서 터치하면 설정 화면으로 |

## 🚀 배포 방법

1. GitHub에 저장소 생성
2. `cheer_app.py`, `requirements.txt` 업로드
3. [Streamlit Cloud](https://streamlit.io/cloud) 접속
4. New app → 저장소 선택 → Main file: `cheer_app.py`
5. Deploy!

## 📱 사용 방법

1. 문구 선택 (샘플 또는 직접 입력)
2. 배경색 선택
3. 효과 선택 (네온싸인, 슬라이드)
4. [전체화면으로 보기] 버튼 클릭
5. 화면 터치하면 설정 화면으로 복귀
