# 🎉 응원 문구 만들기

## 📱 기능
- 📝 8가지 샘플 문구 (에듀테크AI(고) 분임 4개 + 수학 분임 4개)
- ✏️ 직접 입력 가능
- 🎨 6가지 배경색 선택
- 🔤 4가지 한글 글꼴 (Google Fonts)
- 💡 네온싸인 효과
- 🎬 슬라이드 효과 (오른쪽→왼쪽, 천천히)
- ⚡ 깜빡깜빡 효과
- 📐 글씨 크기 자동 조절 (화면에 맞게)
- 📺 기기 전체화면 모드

## 🚀 배포 방법
1. GitHub에 main.py, requirements.txt 업로드
2. Streamlit Cloud에서 배포
3. Main file: main.py

## 📱 사용 방법
1. 문구 선택 또는 직접 입력
2. 배경색, 글꼴, 효과 선택
3. 미리보기에서 확인
4. HTML 다운로드 → 브라우저로 열기
5. 화면 터치로 전체화면 ON/OFF
