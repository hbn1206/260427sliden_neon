# 📣 응원 문구 LED (모바일)

분임별 응원 문구를 모바일에서 전체화면으로 띄우는 단일 페이지 앱입니다.

## 기능
- 분임 선택: 에듀테크AI(고) / 수학
- 예시 문구 4종 (탭하여 즉시 입력)
- 직접 입력 (줄바꿈 반영)
- 효과 2종
  - 🌈 **무지개 깜빡임**: 빨강 → 주황 → 노랑 → 초록 → 파랑 → 보라 순서로 색이 바뀌며 깜빡임
  - ⏺ **고정**: 사용자가 고른 글자색 그대로
- 글자색 / 배경색 선택
- 모바일 전용 글꼴 7종 (Black Han Sans, Noto Sans KR, Do Hyeon, Jua, Gugi, Gaegu, Nanum Pen Script)
- 미리보기에 항상 전체 문구가 보이도록 자동 크기 조절
- 🚀 전체화면 모드: 글자 높이 화면의 약 70% 차지
- 전체화면에서 화면 어디나 한 번 탭하면 설정 그대로 복귀
- (지원 기기) 화면 꺼짐 방지

## 배포 (GitHub Pages)
1. 새 저장소 생성 (Public)
2. `index.html` 업로드 → Commit
3. Settings → Pages → Branch: `main / (root)` → Save
4. 1~2분 후 안내된 주소를 모바일 브라우저로 접속

## 로컬 사용
`index.html` 더블클릭 → 브라우저 실행
