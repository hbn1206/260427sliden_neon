# 📣 응원 문구 LED (모바일)

분임별 응원 문구를 휴대폰 화면에 가득 띄워주는 1파일 웹앱입니다.

## 🚀 가장 쉬운 배포 (GitHub Pages)
1. GitHub에서 새 저장소 생성 (Public)
2. `index.html` 업로드 → Commit
3. Settings → Pages → Branch: `main` / `(root)` → Save
4. 안내된 주소를 모바일 브라우저로 접속

## ✨ 기능
- 분임: **에듀테크AI(고)**, **수학**
- 예시 문구 4종 탭 한 번에 입력
- 직접 입력 가능
- 효과: **흐르기 / 깜빡임 / 무지개 / 고정**
- 글자색 / 배경색 / 속도 조절
- 실시간 미리보기
- 🚀 전체화면 모드(한 번 탭하면 복귀, 옵션 유지)
- 화면 꺼짐 방지(Wake Lock, 지원 기기)

## 🔧 동작 방식
- **흐르기**: 화면 중앙에서 시작해, 한 세트(문구+여백) 폭만큼 이동 후
  바로 다음 세트가 이어지는 **이음새 없는 무한 루프**
- **깜빡임/무지개/고정**: 이진 탐색으로 폰트 크기를 자동 조정해
  **모든 글씨가 한 화면에** 보이도록 맞춤
