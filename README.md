# 🎉 응원 문구 웹페이지

태블릿과 모바일에서 사용할 수 있는 응원 문구 표시 앱입니다.

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| ✏️ 직접 입력 | 원하는 응원 문구 자유롭게 입력 |
| 📝 샘플 문구 | 에듀테크AI(고) 분임, 수학 분임 등 |
| 💡 네온싸인 | 화려한 네온 조명 효과 |
| 🎬 슬라이드 | 오른쪽→왼쪽 슬라이드 (읽기 편한 속도) |
| 🎨 배경 색상 | 6가지 배경색 + 자동 글자색 |
| 📺 전체화면 | 버튼 클릭으로 전체화면 전환 |
| 📱 반응형 | 태블릿, 모바일 완벽 지원 |

## 🎨 색상 조합

| 배경색 | 글자색 | 네온색 |
|--------|--------|--------|
| 🖤 검정 | 흰색 | 시안(청록) |
| ❤️ 빨강 | 노란색 | 노란색 |
| 💙 파랑 | 흰색 | 연두색 |
| 💚 초록 | 흰색 | 핑크색 |
| 💜 보라 | 시안 | 시안 |
| 🤍 흰색 | 핑크 | 핑크 |

## 🚀 배포 방법

### Streamlit Cloud 배포

1. GitHub에 새 저장소 생성
2. 파일 업로드:
   - `cheer_app.py`
   - `requirements.txt`
3. [streamlit.io/cloud](https://streamlit.io/cloud) 접속
4. "New app" → GitHub 저장소 선택
5. Main file: `cheer_app.py`
6. "Deploy" 클릭

## 📱 사용 방법

1. 왼쪽 메뉴(☰)를 열어 설정
2. 샘플 문구 선택 또는 직접 입력
3. 배경색 선택 (글자색 자동 변경)
4. 네온싸인/슬라이드 효과 선택
5. 📺 전체화면 버튼 클릭
6. 태블릿을 들고 응원! 🎉

## 💡 팁

- **전체화면 종료**: ESC 키
- **슬라이드 속도**: 15초 (읽기 편한 속도)
- **슬라이드 방향**: 오른쪽 → 왼쪽
