# 📣 응원 문구 웹페이지

태블릿이나 모바일에서 응원 문구를 전체화면으로 표시하는 웹앱입니다.

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| ✏️ 직접 입력 | 원하는 응원 문구 자유롭게 입력 |
| 📝 샘플 문구 | 에듀테크AI(고) 분임, 수학 분임 문구 선택 |
| 💡 네온싸인 | 화려한 네온 조명 효과 |
| 🎬 슬라이드 | 오른쪽→왼쪽 슬라이드 애니메이션 |
| 📺 전체화면 | **기기 전체화면** 모드 지원 |
| 👆 터치 복귀 | 전체화면에서 터치하면 설정 화면으로 복귀 |
| 🎨 배경색 자동 | 배경색에 맞는 글자색 자동 변경 |

## 🚀 Streamlit Cloud 배포 방법

1. GitHub에 새 저장소 생성
2. `cheer_app.py`, `requirements.txt` 파일 업로드
3. [streamlit.io/cloud](https://streamlit.io/cloud) 접속
4. "New app" → 저장소 선택 → Main file: `cheer_app.py`
5. "Deploy" 클릭

## 📱 사용 방법

1. 왼쪽 메뉴에서 문구 선택 또는 직접 입력
2. 배경색 선택 (글자색 자동 변경)
3. 네온싸인/슬라이드 효과 선택
4. **[📺 전체화면으로 보기]** 버튼 클릭
5. 기기 전체화면으로 응원!
6. **화면 터치** → 설정 화면으로 복귀

## 🎨 배경색별 글자색

| 배경색 | 글자색 | 네온색 |
|--------|--------|--------|
| 🖤 검정 | 흰색 | 시안 |
| ❤️ 빨강 | 노란색 | 노란색 |
| 💙 파랑 | 흰색 | 연두색 |
| 💚 초록 | 흰색 | 핑크색 |
| 💜 보라 | 시안 | 시안 |
| 🤍 흰색 | 핑크 | 핑크 |
