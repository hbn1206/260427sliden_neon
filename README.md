# 📣 모바일 응원 문구 LED

분임별 응원 문구를 모바일에서 LED 전광판처럼 전체화면으로 보여주는 단일 HTML 앱입니다.

## ✨ 기능
- 분임 선택: 에듀테크AI(고) / 수학 — 각 4종 예시 문구
- 직접 입력 + 실시간 미리보기 (전체 문구가 한눈에 보임)
- 효과 3종
  - 🌈 **무지개 깜빡임** (빨강→주황→노랑→초록→파랑→보라 순으로 색이 바뀌며 깜빡임)
  - ✨ **깜빡임** (선택한 글자색으로 켜졌다 꺼졌다)
  - ⏺ **고정**
- 글자색 / 배경색 / 모바일 친화 글꼴 7종
- 🚀 전체화면 버튼 — 화면을 **꽉 채워 글자 최대 크기**로 표시
- 전체화면에서 화면을 한 번 탭하면 설정 그대로 복귀
- 화면 꺼짐 방지(Wake Lock)·화면 회전 시 자동 크기 재조정

## 🚀 GitHub Pages 배포 방법
1. GitHub에서 새 저장소 생성 (Public)
2. `index.html` 업로드 후 Commit
3. **Settings → Pages → Branch: `main` / `(root)`** → Save
4. 1~2분 후 표시되는 주소를 **모바일 브라우저**로 접속
5. (선택) 모바일 브라우저 메뉴 → "홈 화면에 추가"

## 💻 로컬 실행
`index.html`을 더블클릭해서 브라우저로 열기만 하면 됩니다.
