# 📣 모바일 응원 문구 LED

깃허브 + 모바일 브라우저에서 바로 실행되는 단일 HTML 응원 문구 보드입니다.

## 🚀 가장 쉬운 실행 (GitHub Pages)
1. GitHub에서 새 저장소 생성 (Public)
2. `index.html` 업로드 → Commit
3. Settings → Pages → Branch: `main` / `(root)` → Save
4. 1~2분 후 안내되는 주소를 **모바일 브라우저로 열기**
5. (선택) 브라우저 메뉴 → "홈 화면에 추가"

## ✨ 기능
- 분임 선택: 에듀테크AI(고) / 수학
- 분임별 예시 문구 4종 (탭 한 번에 입력)
- 직접 입력 / 색상 / 효과(흐르기·깜빡임·무지개·고정) / 속도
- 실시간 미리보기
- 🚀 전체화면 버튼 — 폰 액정에 글씨 가득
- 전체화면에서 아무 곳이나 터치 → 설정 화면으로 복귀(설정 유지)
- 화면 회전 시 자동 크기 재계산
- 화면 꺼짐 방지 (Wake Lock 지원 기기)

## 🎯 효과별 동작
- **흐르기**: 끊김 없이 글씨가 좌→우로 무한 반복 흘러갑니다.
- **깜빡임 / 무지개 / 고정**: 모든 글씨가 **한 화면에 가득** 보이도록 자동 크기 조절.
