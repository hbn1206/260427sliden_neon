# 🎉 응원 문구 만들기

모바일/태블릿에서 전체화면 응원 문구를 띄울 수 있는 웹앱입니다.

## 📱 주요 기능

- 📝 **8가지 샘플 문구** - 에듀테크AI(고) 분임, 수학 분임 각 4가지
- ✏️ **직접 입력** - 원하는 문구 자유롭게 입력
- 🎨 **6가지 배경색** - 자동 글자색 변경
- 🔤 **4가지 글꼴** - 한글 예쁜 폰트
- 💡 **네온싸인 효과** - 빛나는 네온 조명
- 🎬 **슬라이드 효과** - 오른쪽→왼쪽 이동
- ⚡ **깜빡깜빡 효과** - 깜빡이는 애니메이션
- 👀 **미리보기** - 실시간으로 효과 확인
- 📺 **전체화면 모드** - HTML 다운로드 후 실행

## 🚀 배포 방법

1. GitHub 저장소 생성
2. `main.py`, `requirements.txt` 업로드
3. Streamlit Cloud 연결 (Main file: `main.py`)
4. Deploy!

## 📱 사용 방법

1. 앱에서 문구, 배경색, 글꼴, 효과 선택
2. 미리보기로 확인
3. [📥 응원 화면 다운로드] 클릭
4. 다운로드된 HTML 파일을 브라우저로 열기
5. 화면 터치로 전체화면 ON/OFF
